# Falling Box Game

A simple 2D arcade game developed using C++ and Raylib.

## About the Game

The objective is to control a blue circle and avoid a falling red box. The player can move left and right using the arrow keys. If the falling box collides with the player, the game ends.

## Controls

| Key | Action |
|---|---|
| Left Arrow | Move left |
| Right Arrow | Move right |

## Technologies Used

- C++
- Raylib

## Features

- Player movement using keyboard input.
- Falling box with random horizontal respawning.
- Player movement restricted by screen boundaries.
- Collision detection using bounding boxes.
- Game Over screen when a collision occurs.
